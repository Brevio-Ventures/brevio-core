# R12.6: Worker thread termination

Group: Memory and resource leaks. Generated from the rule definitions; do not edit by hand.

## What it catches

Worker thread termination: spawn worker instances call terminate() upon task completion.

## Why

A worker that is never terminated keeps a thread and its memory.

## A bad example

```ts
const w = new Worker(file);
```

## A good example

```ts
const w = new Worker(file);
w.on('message', done).on('message', () => w.terminate());
```
