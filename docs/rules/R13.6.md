# R13.6: Audit event journaling

Group: Observability and logging. Generated from the rule definitions; do not edit by hand.

## What it catches

Audit event journaling: security-critical actions append an immutable audit record.

## Why

Without an audit record you cannot say who changed a role or a key.

## A bad example

```ts
await setRole(user, 'admin');
```

## A good example

```ts
await setRole(user, 'admin');
await audit.append({ actor, action: 'role.set', target: user });
```

## How to silence it

There is no ignore comment. That is on purpose: a comment that silences a rule is the easiest way for an automated author to pass its own gate. Fix the code instead.

To change what the rule flags, edit its definition in `dev_rules.py` or `code_rules/__init__.py`. That is a code change and is reviewed like one.
