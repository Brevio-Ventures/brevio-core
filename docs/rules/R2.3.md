# R2.3: Dual-key entity resolution

Group: Security and tenancy. Generated from the rule definitions; do not edit by hand.

## What it catches

Dual-key entity resolution: discriminate UUID/CUID vs domain/slug before database query.

## Why

An id that is a UUID in one place and a slug in another is looked up in the wrong column.

## A bad example

```ts
findOne({ id: param })
```

## A good example

```ts
const where = isUuid(param) ? { id: param } : { slug: param };
findOne(where)
```
