# R11.6: Optimistic UI rollback

Group: State and concurrency. Generated from the rule definitions; do not edit by hand.

## What it catches

Optimistic UI rollback: optimistic state updates retain rollback snapshot on failure.

## Why

An optimistic update with no snapshot cannot be undone when the server says no.

## A bad example

```ts
setItems([...items, item]); await save(item);
```

## A good example

```ts
const snap = items; setItems([...items, item]);
try { await save(item); } catch { setItems(snap); }
```
