# R1.1: Mobile GPU budget

**Short answer:** Scope blur >=40px to md:/lg: desktop viewports. A large blur is painted on the GPU for every frame. Phones drop frames and heat up.

Group: UI and mobile performance. Status: stable. Generated from the rule definitions; do not edit by hand.

Playground: <https://brevio.pro/tools/agent-guard-playground?rule=R1.1>

## What it catches

Mobile GPU budget: scope blur >=40px to md:/lg: desktop viewports.

## Why

A large blur is painted on the GPU for every frame. Phones drop frames and heat up.

## A bad example

```tsx
<div className="blur-[120px]" />
```

## A good example

```tsx
<div className="blur-none md:blur-[120px]" />
```

## How it is checked

- The harness's pre-flight scan of added lines (`dev_rules.scan_added_lines`); `brevio-core scan` does not run it.
- A one-line card in the prompt of a slice that touches matching files (`dev_rules.slice_micro_rules`).

## How to silence it

A person can silence one finding with `brevio-core: ignore R1.1 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

What the scanner already leaves alone: A line that already scopes the blur with a sm:, md:, lg:, xl: or 2xl: prefix is not flagged.

A scan reads only the lines you add, so a line that was already in the file is not flagged.

To change what the rule flags, edit its definition in `dev_rules.py` or `code_rules/__init__.py`. That is a code change and is reviewed like one.
