# R1.1: Mobile GPU budget

Group: UI and mobile performance. Generated from the rule definitions; do not edit by hand.

## What it catches

Mobile GPU budget: scope blur >=40px to md:/lg: desktop viewports.

## Why

A large blur is painted on the GPU for every frame. Phones drop frames and heat up.

## A bad example

```tsx
<div className="blur-[120px]" />
```

## A good example

```tsx
<div className="blur-none md:blur-[120px]" />
```

## How it is checked

- A pre-flight scan of added lines (`dev_rules.scan_added_lines`).
- A one-line card in the prompt of a slice that touches matching files (`dev_rules.slice_micro_rules`).

## How to silence it

There is no ignore comment. That is on purpose: a comment that silences a rule is the easiest way for an automated author to pass its own gate. Fix the code instead.

What the scanner already leaves alone: A line that already scopes the blur with a sm:, md:, lg:, xl: or 2xl: prefix is not flagged.

A scan reads only the lines you add, so a line that was already in the file is not flagged.

To change what the rule flags, edit its definition in `dev_rules.py` or `code_rules/__init__.py`. That is a code change and is reviewed like one.
