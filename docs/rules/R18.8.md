# R18.8: Document language attribute

Group: Accessibility (WCAG 2.1 AA). Generated from the rule definitions; do not edit by hand.

## What it catches

Document language attribute: html root element specifies valid lang='en' attribute.

## Why

Without a language, a screen reader reads the page in the wrong voice.

## A bad example

```html
<html>
```

## A good example

```html
<html lang="en">
```
