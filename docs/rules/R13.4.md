# R13.4: Metric label cardinality bounding

Group: Observability and logging. Generated from the rule definitions; do not edit by hand.

## What it catches

Metric label cardinality bounding: avoid dynamic user IDs or timestamps in metric labels.

## Why

A user id as a metric label creates a new time series per user and floods the store.

## A bad example

```ts
counter.inc({ userId });
```

## A good example

```ts
counter.inc({ route });
```

- Nothing yet. No scanner and no slice card checks it: it is a standing rule for authors and reviewers.
