# R4.4: Ingestion FK pre-resolution

Group: Database and migrations. Generated from the rule definitions; do not edit by hand.

## What it catches

Ingestion FK pre-resolution: upsert or verify parent workspace before child rows.

## Why

A child row inserted before its parent exists fails, or points at nothing.

## A bad example

```ts
await db.insert(event);
```

## A good example

```ts
await upsertWorkspace(event.workspaceId);
await db.insert(event);
```

## How it is checked

- A one-line card in the prompt of a slice that touches matching files (`dev_rules.slice_micro_rules`).

## How to silence it

There is no ignore comment. That is on purpose: a comment that silences a rule is the easiest way for an automated author to pass its own gate. Fix the code instead.
