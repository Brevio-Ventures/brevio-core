# R18.2: Form control labels

Group: Accessibility (WCAG 2.1 AA). Generated from the rule definitions; do not edit by hand.

## What it catches

Form control labels: every input, select, and textarea element has associated label.

## Why

An input with no label cannot be named by a screen reader or clicked by its label.

## A bad example

```tsx
<input type="email" />
```

## A good example

```tsx
<label htmlFor="email">Email</label>
<input id="email" type="email" />
```
