# R16.1: Lockfile integrity enforcement

**Short answer:** CI installs strictly via frozen lockfiles (pnpm --frozen). Without a frozen lockfile CI installs different versions than you tested.

Group: Supply chain. Status: stable. Generated from the rule definitions; do not edit by hand.

Playground: <https://brevio.pro/tools/agent-guard-playground?rule=R16.1>

## What it catches

Lockfile integrity enforcement: CI installs strictly via frozen lockfiles (pnpm --frozen).

## Why

Without a frozen lockfile CI installs different versions than you tested.

## A bad example

```
pnpm install
```

## A good example

```
pnpm install --frozen-lockfile
```

## How it is checked

- Nothing yet. No scanner and no slice card checks it: it is a standing rule for authors and reviewers.

## How to silence it

A person can silence one finding with `brevio-core: ignore R16.1 -- reason` on the line or the line above. Without the reason it does not count. An agent cannot silence it: the agent hook and the MCP tools never honour the comment, and a pull request that adds one is reported until a reviewer allows it. Fixing the code is still the better answer.

To change what the rule flags, edit its definition in `dev_rules.py` or `code_rules/__init__.py`. That is a code change and is reviewed like one.
