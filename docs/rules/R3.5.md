# R3.5: Transactional outbox

Group: Billing and money. Generated from the rule definitions; do not edit by hand.

## What it catches

Transactional outbox: persist DB state before enqueuing external side effects.

## Why

If the process dies between the queue and the database, the outside world and your data disagree.

## A bad example

```ts
await queue.send(msg);
await db.insert(row);
```

## A good example

```ts
await db.insert(row);
await queue.send(msg);
```

## How to silence it

There is no ignore comment. That is on purpose: a comment that silences a rule is the easiest way for an automated author to pass its own gate. Fix the code instead.
