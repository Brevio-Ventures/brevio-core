# R11.3: Race condition prevention

Group: State and concurrency. Generated from the rule definitions; do not edit by hand.

## What it catches

Race condition prevention: UI mutations abort pending conflicting requests via AbortController.

## Why

A slow first request can overwrite the result of a newer one.

## A bad example

```ts
fetch(url).then(setData);
```

## A good example

```ts
ctrl.abort(); ctrl = new AbortController();
fetch(url, { signal: ctrl.signal }).then(setData);
```
