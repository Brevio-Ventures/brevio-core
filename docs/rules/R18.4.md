# R18.4: Contrast ratio minimum

Group: Accessibility (WCAG 2.1 AA). Generated from the rule definitions; do not edit by hand.

## What it catches

Contrast ratio minimum: text satisfies 4.5:1 minimum contrast ratio against background.

## Why

Light grey text on white cannot be read by many people.

## A bad example

```css
color: #aaa; background: #fff;
```

## A good example

```css
color: #595959; background: #fff;  /* 7:1 */
```

- Nothing yet. No scanner and no slice card checks it: it is a standing rule for authors and reviewers.
