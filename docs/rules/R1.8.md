# R1.8: Async polling hygiene

Group: UI and mobile performance. Generated from the rule definitions; do not edit by hand.

## What it catches

Async polling hygiene: clear intervals on unmount and stop polling on terminal states.

## Why

A poll that is never stopped keeps calling the server after the user has left.

## A bad example

```ts
useEffect(() => { setInterval(poll, 1000); }, []);
```

## A good example

```ts
useEffect(() => { const t = setInterval(poll, 1000); return () => clearInterval(t); }, []);
```
