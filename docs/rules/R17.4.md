# R17.4: Next/Image usage

Group: React and Next.js patterns. Generated from the rule definitions; do not edit by hand.

## What it catches

Next/Image usage: production UI renders next/image for optimized srcset and layout stability.

## Why

A plain img has no resizing, no srcset and no reserved space.

## A bad example

```tsx
<img src="/a.png" />
```

## A good example

```tsx
<Image src="/a.png" alt="" width={400} height={300} />
```

## How it is checked

- Nothing yet. No scanner and no slice card checks it: it is a standing rule for authors and reviewers.

There is no ignore comment. That is on purpose: a comment that silences a rule is the easiest way for an automated author to pass its own gate. Fix the code instead.
