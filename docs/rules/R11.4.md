# R11.4: Deterministic reducer purity

Group: State and concurrency. Generated from the rule definitions; do not edit by hand.

## What it catches

Deterministic reducer purity: state reducers remain pure functions without side effects.

## Why

A reducer with side effects gives a different state each time it is replayed.

## A bad example

```ts
case 'add': log(action); state.n++; return state;
```

## A good example

```ts
case 'add': return { ...state, n: state.n + 1 };
```
