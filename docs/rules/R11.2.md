# R11.2: No dangling unawaited promises

Group: State and concurrency. Generated from the rule definitions; do not edit by hand.

## What it catches

No dangling unawaited promises: promise chains either return or await explicitly.

## Why

A promise nobody awaits fails with no one listening.

## A bad example

```ts
save();
```

## A good example

```ts
await save();
```

- Nothing yet. No scanner and no slice card checks it: it is a standing rule for authors and reviewers.
