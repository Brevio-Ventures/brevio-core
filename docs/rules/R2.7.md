# R2.7: Secure cookie & CORS hygiene

Group: Security and tenancy. Generated from the rule definitions; do not edit by hand.

## What it catches

Secure cookie & CORS hygiene: HttpOnly, Secure, SameSite, no wildcard CORS with credentials.

## Why

A cookie without these flags can be read by scripts or sent from another site.

## A bad example

```ts
res.cookie('sid', id);
```

## A good example

```ts
res.cookie('sid', id, { httpOnly: true, secure: true, sameSite: 'lax' });
```

## How to silence it

There is no ignore comment. That is on purpose: a comment that silences a rule is the easiest way for an automated author to pass its own gate. Fix the code instead.

To change what the rule flags, edit its definition in `dev_rules.py` or `code_rules/__init__.py`. That is a code change and is reviewed like one.
