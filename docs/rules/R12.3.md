# R12.3: Stream disposal hygiene

Group: Memory and resource leaks. Generated from the rule definitions; do not edit by hand.

## What it catches

Stream disposal hygiene: open readable/writable streams explicitly call close() or pipe safely.

## Why

A stream that is not closed keeps its file or socket open.

## A bad example

```ts
const s = fs.createReadStream(p);
```

## A good example

```ts
const s = fs.createReadStream(p);
s.on('end', () => s.close());
```
