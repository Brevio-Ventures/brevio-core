# R14.2: Password hash modern algorithms

Group: Auth and sessions. Generated from the rule definitions; do not edit by hand.

## What it catches

Password hash modern algorithms: use Argon2id or bcrypt with appropriate work factor.

## Why

A fast hash can be brute forced. A slow one cannot, at the same cost.

## A bad example

```py
hash = sha256(password)
```

## A good example

```py
hash = argon2id.hash(password)
```
