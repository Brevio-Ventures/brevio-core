# R5.2: HTTP empty-body hygiene

Group: Reliability and fallbacks. Generated from the rule definitions; do not edit by hand.

## What it catches

HTTP empty-body hygiene: 204 returns empty body; 200 JSON sets Content-Type.

## Why

A 204 with a body, or JSON without a Content-Type, breaks clients and proxies.

## A bad example

```ts
return new Response('ok', { status: 204 });
```

## A good example

```ts
return new Response(null, { status: 204 });
```
