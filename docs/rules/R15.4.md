# R15.4: Image broken state fallback

Group: Error boundaries and fallback rendering. Generated from the rule definitions; do not edit by hand.

## What it catches

Image broken state fallback: img / Image tags provide alt and error state fallback.

## Why

A broken image with no fallback leaves a hole in the layout.

## A bad example

```tsx
<img src={url} alt="" />
```

## A good example

```tsx
<img src={url} alt="Team photo" onError={useFallback} />
```

## How it is checked

- Nothing yet. No scanner and no slice card checks it: it is a standing rule for authors and reviewers.
