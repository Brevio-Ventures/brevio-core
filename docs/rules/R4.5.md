# R4.5: Bounded pagination

**Short answer:** Enforce hard LIMIT (<=100) on every list query. A list query with no limit returns the whole table as it grows.

Group: Database and migrations. Status: stable. Generated from the rule definitions; do not edit by hand.

## What it catches

Bounded pagination: enforce hard LIMIT (<=100) on every list query.

## Why

A list query with no limit returns the whole table as it grows.

## A bad example

```ts
db.select().from(orders)
```

## A good example

```ts
db.select().from(orders).limit(100)
```
