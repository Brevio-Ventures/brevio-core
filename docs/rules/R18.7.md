# R18.7: Visible focus rings

Group: Accessibility (WCAG 2.1 AA). Generated from the rule definitions; do not edit by hand.

## What it catches

Visible focus rings: interactive elements retain visible focus outline for keyboard users.

## Why

People who use a keyboard need to see where the focus is.

## A bad example

```css
button:focus { outline: none; }
```

## A good example

```css
button:focus-visible { outline: 2px solid #1a73e8; }
```
