# R5.3: Bounded retry with jitter

Group: Reliability and fallbacks. Generated from the rule definitions; do not edit by hand.

## What it catches

Bounded retry with jitter: retry only transient 429/502/503/504 with backoff + jitter.

## Why

Retrying every error, at once, turns one outage into many.

## A bad example

```ts
while (true) { try { return await call(); } catch {} }
```

## A good example

```ts
retry(call, { on: [429, 502, 503, 504], backoff: 'exponential', jitter: true })
```
