# R11.8: Thread-safe singleton initialization

Group: State and concurrency. Generated from the rule definitions; do not edit by hand.

## What it catches

Thread-safe singleton initialization: singletons use atomic locks or double-checked init.

## Why

Two threads can both create the singleton.

## A bad example

```py
if (!inst) inst = make();
```

## A good example

```py
with lock:
    if inst is None:
        inst = make()
```
