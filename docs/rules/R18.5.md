# R18.5: No click handlers on non-interactive elements

Group: Accessibility (WCAG 2.1 AA). Generated from the rule definitions; do not edit by hand.

## What it catches

No click handlers on non-interactive elements: divs/spans with onClick specify role='button'.

## Why

A div with a click handler is not a button for the keyboard or a screen reader.

## A bad example

```tsx
<div onClick={open}>Open</div>
```

## A good example

```tsx
<div onClick={open} role="button" tabIndex={0}>Open</div>
```

## How it is checked

- A diff scan of added lines (`code_rules.scan_added_lines_for_rules`).

## How to silence it

There is no ignore comment. That is on purpose: a comment that silences a rule is the easiest way for an automated author to pass its own gate. Fix the code instead.

What the scanner already leaves alone: A div with role= after its onClick on the same line is not flagged.

A scan reads only the lines you add, so a line that was already in the file is not flagged.

To change what the rule flags, edit its definition in `dev_rules.py` or `code_rules/__init__.py`. That is a code change and is reviewed like one.
