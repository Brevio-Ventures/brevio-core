# Code of conduct

This project follows the Contributor Covenant, version 2.1. Read it at
https://www.contributor-covenant.org/version/2/1/code_of_conduct/ and treat it as part of this repository.

In short: be respectful, assume good faith, and do not harass anyone.

To report a problem, write to security@brevio.pro with "Conduct" in the subject. Reports are handled in private.
